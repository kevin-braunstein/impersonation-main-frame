Each section below shows the same five values for a different frame in this tab: the Initial column is captured synchronously in that frame's very first <script> tag; the Current column is re-collected every second. Current is highlighted green when it matches Initial and red when it doesn't. Any call that failed or returned an unsupported/undefined result (e.g. window.fireglassGetRendererPolicy not being defined) is highlighted red regardless of whether it matches, since a consistent failure is still a failure.

Note: navigator.userAgentData's high-entropy values (e.g. full version list, platform version) can only be read asynchronously per spec, so they only ever appear in the Current column — never in Initial, and that's expected.

Set OOPIF_URL_PLACEHOLDER in the last <script> below (or pass ?oopif=<url> in this page's query string) to wherever you're hosting iframe-oopif.html. It must be on a genuinely different site (a different registrable domain, e.g. frame-a.test vs frame-b.test) — a different port on the same host is usually still the same site under Chromium's Site Isolation and will not end up out-of-process.
